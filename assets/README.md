# Assets

Use this directory for production website assets that are committed to the repo.

## Expected structure

- `assets/fonts/`: TT Lakes and any local webfont files.
- `assets/images/`: logo, favicon, testimonial, partner, and page imagery.

Prefer committed, optimized assets for launch-critical brand files such as the favicon and TT Lakes font. External providers like logo.dev can remain for partner logos if the production token and domains are confirmed.
